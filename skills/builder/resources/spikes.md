# Spikes

Use only for an assigned disposable experiment.

- Confirm one feasibility question, scratch path, fixture, and proving command.
- Use the assigned scratch path exactly. If it is missing or ambiguous, return a blocker instead of inventing one.
- Create only the requested fixture; do not redesign the experiment or production system.
- Keep production files unchanged.
- Run commands only when assigned to the slice.
- Return observed output, limitations, and blocker; leave interpretation to the assigned verifier or planner.
- Treat the fixture as disposable. Promotion requires an approved production plan.
